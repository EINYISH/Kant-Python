#미니 프로젝트 발제 — 쇼핑몰 장바구니 & 할인 쿠폰

##실행 방법
터미널에서 소스 파일이 있는 폴더로 이동 한 뒤 실행합니다. 

```bash
python3 mini_project.py
```
실행하면 다음과 같은 메뉴 목록을 볼 수 있다. 

```
---------------------------------------------------------
1.상품목록 2.담기 3.빼기 4.장바구니 5.쿠폰 6.결제 q.종료
---------------------------------------------------------
```

## 사용 예시



### 1. 상품 목록 보기

```
선택: 1
1. 무선 이어폰    89000원  (재고 3개)
2. 텀블러         15000원  (재고 10개)
3. 보조배터리     32000원  (재고 5개)
4. 마우스패드      9000원  (품절)
5. USB 허브       18000원  (재고 4개)
```

### 2. 장바구니에 담기

상품 번호와 수량을 입력하면 장바구니에 담깁니다.

```
선택: 2
상품 번호: 1
수량: 3
무선 이어폰 3개를 담았습니다.
```

품절된 상품을 선택하면 안내 메시지가 출력됩니다.

```
선택: 2
상품 번호: 4
품절된 상품입니다.
```

이어서 텀블러 5개를 추가합니다.

```
선택: 2
상품 번호: 2
수량: 5
텀블러 5개를 담았습니다.
```

### 3. 장바구니에서 빼기

```
선택: 3
상품 번호: 1
무선 이어폰을 뺐습니다.
```

### 4. 쿠폰 적용

```
선택: 5
1. 쿠폰 없음
2. 10% 할인 (최대 5,000원)
3. 3,000원 할인 (20,000원 이상 구매 시)
쿠폰 번호: 3
[3,000원 할인 (20,000원 이상 구매 시)] 쿠폰을 적용했습니다.
```

### 5. 장바구니 확인

담은 상품과 쿠폰 할인, 배송비가 반영된 최종 결제 금액을 확인할 수 있습니다.

```
선택: 4
---------------------------------------------------------
텀블러 X 5    75000원
---------------------------------------------------------
[3,000원 할인 (20,000원 이상 구매 시 )] 쿠폰을 적용했습니다. 
상품 합계            75000원
할인                -3000원 [3,000원 할인 (20,000원 이상 구매 시)]
배송비               0원
결제 금액            72000원
```

### 6. 결제

```
선택: 6
영수증 출력
결제가 완료되었습니다. 감사합니다!
```

### 7. 종료

```
선택: q
온라인 쇼핑몰을 종료합니다.
```
